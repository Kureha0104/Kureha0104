## 02 // FEATURED PROJECTS

### 🎓 Edu Flow

<a href="https://github.com/Kureha0104/Edu-flow">
<img src="https://raw.githubusercontent.com/Kureha0104/Edu-flow/Kureha0104/assets/logo.jpg" width="180" alt="Edu Flow project logo" />
</a>

**A shared learning workflow for teachers, students, and parents.**

An education plugin for erxes that brings homework, feedback, and student progress into one place. The demo includes AI-assisted lesson planning, homework photo review, adaptive quizzes, and parent updates.

**Stack:** TypeScript · React · Tailwind CSS · Node.js · GraphQL · MongoDB · Redis · erxes

**Achievement:** 5th Place — Hacktoberfest 2026

[View repository →](https://github.com/Kureha0104/Edu-flow) · [Demo walkthrough →](https://github.com/Kureha0104/Edu-flow#demo-walkthrough)

### 🎙️ Speech-to-Text

**Turn spoken words into a live transcript in the browser.**

A speech recognition project with language selection, including Mongolian. Uses the Web Speech API; recognition availability depends on browser and language support.

**Stack:** HTML · CSS · JavaScript · Web Speech API

**Achievement:** 1st Place — Speech-to-Text Hackathon

[View repository →](https://github.com/Kureha0104/Speech-To-Text)

### 📰 Student News Platform

**A place for Mongolian university communities to share news.**

Browse student articles, publish posts with images, and filter stories by category. Built with the **Vibe** team for IT Park Mongolia's 19th “AI Coding” Hackathon.

**Stack:** HTML · CSS · JavaScript · Tailwind CSS · Vercel

**Achievement:** 1st Place — with Kh. Tortuvshiin
